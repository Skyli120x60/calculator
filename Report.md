# Отчёт: калькулятор Фадеева (C# WPF, .NET 8)

## 1. Назначение

Настольное приложение-калькулятор с вычислением арифметических выражений, историей операций, светлой/тёмной темой и локализацией интерфейса (RU/EN). Логика вынесена в отдельную библиотеку; интерфейс построен по MVVM.

## 2. Технологии

| Компонент | Технология |
|-----------|------------|
| Платформа | .NET 8 |
| UI | WPF (`net8.0-windows`) |
| Библиотека | Class Library (`net8.0`) |
| Тесты | xUnit |
| Сериализация | System.Text.Json |

## 4. Библиотека `FadeevCalculatorLib`

### 4.1 Парсинг и вычисление

Реализован алгоритм **Shunting-yard** (перевод в обратную польскую запись) в классе `ReversePolishNotation`. Вычисление проходит три этапа: токенизация строки, перевод в RPN, вычисление стека.

Поддерживаемые возможности:
- Операторы: `+`, `-`, `*`, `/`, `^` (целая степень)
- Скобки `(` `)` с корректным приоритетом
- Унарный минус (в начале выражения и после оператора/скобки)
- Десятичные числа с точкой или запятой в качестве разделителя
- Тип результата — `decimal` (исключает проблемы с точностью floating-point)
- `checked`-арифметика — переполнение бросает `OverflowException`
- Деление на ноль — `DivideByZeroException`
- Дробный показатель степени — `NotSupportedException`

Примечание: унарный минус после `^` должен быть в скобках: `2^(-2)`, а не `2^-2` — особенность алгоритма Shunting-yard.

### 4.2 Модели

**CalculationHistoryItem** — иммутабельная запись истории:
- `Expression` — строка выражения
- `Result` — результат типа `decimal`
- `Timestamp` — время вычисления (UTC)
- Сериализуется через `[JsonConstructor]` без публичных сеттеров

**ThemeSettings** — настройки темы:
- `IsDarkTheme` — тёмная/светлая тема
- `AccentColor` — акцентный цвет в формате HEX (`#1E90FF` по умолчанию)
- `Default` — статическое поле с настройками по умолчанию

### 4.3 Сервисы

**AppPaths** — внутренний хелпер, возвращает путь к файлам приложения в `%LocalAppData%\FadeevCalculator\`.

**HistoryService** — загрузка/сохранение истории в `history.json`. При повреждённом файле возвращает пустой список без исключения.

**SettingsService** — загрузка/сохранение настроек в `settings.json`. При отсутствии файла возвращает `ThemeSettings.Default`.

Оба сервиса используют общие `static readonly JsonSerializerOptions` для чтения и записи — без лишних аллокаций.

### 4.4 CalculatorEngine

Фасад над библиотекой:
- `Calculate(string)` — вычисление и запись в историю
- `Evaluate(string)` — вычисление без добавления в историю (предпросмотр)
- `GetHistory()` — список истории (до 200 записей, старые вытесняются)
- `ClearHistory()` — очистка истории с сохранением на диск
- `GetThemeSettings()` / `UpdateThemeSettings()` — работа с темой
- `SaveAll()` — явное сохранение истории и настроек на диск

## 5. Приложение `FadeevCalculatorApp`

### 5.1 Архитектура

Приложение построено по паттерну **MVVM**:
- `MainViewModel` — вся логика представления, реализует `INotifyPropertyChanged`
- `RelayCommand` — универсальная реализация `ICommand`
- `StringToBrushConverter` — конвертер `IValueConverter`, преобразует HEX-строку в `Brush` на стороне View
- `MainWindow.xaml.cs` — минимальный code-behind: инициализация DataContext, обработка клавиатуры

ViewModel не содержит зависимостей на `System.Windows.Media` — цвета хранятся как HEX-строки и конвертируются в `Brush` только в XAML через `StringToBrushConverter`.

### 5.2 Интерфейс

Дизайн выполнен в стиле Windows 11 Calculator:
- Минималистичный хедер с названием и кнопками переключения темы/языка
- Дисплей: выражение серым шрифтом сверху, результат крупным светлым шрифтом снизу
- Предпросмотр результата в реальном времени — результат обновляется после каждого введённого символа без нажатия `=`
- Клавиатура с иерархией стилей: служебные кнопки (`(`  `)` `CE` `C` `xʸ` `⌫`), цифры, операторы (`÷` `×` `−` `+`), кнопка `=`
- Панель истории справа с прокруткой и кнопкой очистки; клик по записи восстанавливает выражение
- Переключение тёмной/светлой темы с сохранением настройки
- Визуальная обратная связь кнопок: изменение прозрачности при наведении и нажатии
- Локализация RU/EN: все строки интерфейса переключаются кнопкой языка

### 5.3 Ввод

| Источник | Действие |
|---|---|
| Кнопки | Мышь |
| Цифры и операторы | Клавиатура |
| Точка / запятая | Десятичный разделитель |
| Скобки `(` `)` | Клавиатура |
| Enter / Return | Вычисление |
| Backspace | Удаление последнего символа |
| Escape | Полная очистка |

### 5.4 Сохранение данных

При закрытии окна вызывается `MainViewModel.Persist()` → `CalculatorEngine.SaveAll()` — история и настройки темы сохраняются в JSON-файлы в `%LocalAppData%\FadeevCalculator\`.

## 6. Тесты `FadeevCalculatorTests`

Покрытие (xUnit, 25+ тестов):

| Группа | Что проверяется |
|---|---|
| Базовые операции | `+` `-` `*` `/` `^` через `[Theory]` |
| Десятичные числа | Точка и запятая как разделитель, `0.1+0.2` |
| Приоритет и ассоциативность | `*` перед `+`, правоассоциативность `^` |
| Унарный минус | В начале, после оператора, в скобках |
| Степень | `5^0`, `5^1`, `2^(-2)`, дробный показатель |
| Негативные кейсы | Деление на ноль, переполнение, непарные скобки, пустое выражение, недопустимые символы |
| История | Добавление, предпросмотр без записи, cap на 200 записей, персистентность |
| Тема | Получение, обновление, персистентность, null-аргумент |
| Очистка | `ClearHistory` с сохранением |

Запуск:
```bash
dotnet test FadeevCalculator.sln -c Release
```
